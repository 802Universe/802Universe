STATUS CODES - IEEE 802.11-2020 Table 9-50 | Returned in Auth / Assoc / Action responses | Wireshark: wlan.fixed.status_code34 rows#

CodeName (spec)MeaningEscalation Engineer Notes / Common Root Cause
0SUCCESSOperation succeeded.The only good status. Anything else in Assoc/Auth Resp = investigate.
1Unspecified failureGeneric failure.Vendor catch-all - check AP logs, often RSN/capability parse issue.
10Cannot support all requested capabilitiesCapability Info mismatch.Client requested capability bits AP cannot honor (e.g. short slot).
11Reassociation denied - no prior associationAP has no context for reassoc.Client roamed but target AP lost/never had its entry - client falls back to full assoc.
12Association denied - outside scope of standardVendor/policy denial.Commonly used by band-steering / load-balancing features to push a client away.
13Unsupported authentication algorithmAuth alg number not supported.Client tried SAE (3) on WPA2-only AP, Shared Key (1) on open, FT (2) without 11r, etc.
14Auth transaction sequence out of orderAuth seq number unexpected.Retry storms or state mismatch after interference; also SAE confirm before commit.
15Authentication challenge failureShared-key WEP challenge failed.Legacy WEP only. In SAE, wrong password surfaces as failed Confirm or 4-way timeout (Reason 15) instead.
16Authentication timeoutPeer too slow.AP-side timer expired waiting for next auth frame.
17Association denied - AP capacityAP cannot handle more STAs.Max-clients-per-radio/BSS reached - check load balancing settings.
18Association denied - basic ratesSTA does not support all BasicRates.Classic: AP requires 24 Mbps basic, legacy client only 1-11. Check rate config.
19Association denied - short preambleLegacy DSSS preamble mismatch.2.4 GHz legacy interop.
25Association denied - short slot time2.4 GHz slot-time capability.Legacy interop.
27Association denied - HT featuresSTA lacks required HT support.AP set to HT-required (greenfield/N-only).
30Association rejected temporarilyTry again after comeback time.SEEN WITH PMF: AP in SA-Query with that MAC - client must wait Association Comeback (TIE type 3). Also used by steering.
31Robust mgmt frame policy violationPMF policy mismatch.MFPR/MFPC conflict - e.g. client no-PMF on WPA3 (PMF required) network.
32Unspecified QoS failureGeneric QoS.-
33Denied - insufficient bandwidth (QAP)Admission control full.Voice/TSPEC admission (WMM-AC) limit reached.
34Denied - poor channel conditionsAP judged link too weak.Some vendors reject weak clients (RSSI-based assoc rejection).
35Denied - not a QoS STAQoS BSS requires QoS support.-
37Request declinedPeer refused (generic).Common in ADDBA rejects - sender falls back to non-aggregated.
38Invalid parametersRequest parameters invalid.ADDBA with unsupported buffer size, bad TSPEC values.
40Invalid information elementMalformed IE.Fuzzed/buggy client IEs; interop bugs between chipset vendors.
41Invalid group cipherGroup cipher mismatch.RSN IE mismatch - e.g. client offers TKIP group on CCMP-only BSS.
42Invalid pairwise cipherPairwise cipher mismatch.WPA3-SAE requires CCMP - client offering TKIP rejected here.
43Invalid AKMPAKM mismatch.Client PSK vs AP 802.1X, missing SAE AKM (8; 24 = SAE-EXT-KEY) etc. Check RSN sheet AKM table.
44Unsupported RSN IE versionRSN version ≠ 1.Corrupt or nonstandard RSN IE.
45Invalid RSN IE capabilitiesRSN Capabilities field invalid.Often PMF bit combinations (MFPR=1 with MFPC=0 is illegal).
46Cipher suite rejected by security policyPolicy denies offered cipher.WPA3-Enterprise 192-bit mode rejecting non-GCMP-256 suites.
53Invalid PMKIDPMKID not found/expired.PMK caching / OKC / FT failures - client cached a PMKID the AP no longer has. Watch after controller failover.
76Anti-clogging token requiredSAE DoS protection engaged.NORMAL under SAE load/attack: client must repeat commit echoing token. Frequent = possible DragonDrain-style flood.
77Finite cyclic group not supportedSAE group rejected.Client offered SAE group AP disabled (19 = P-256 is the universal default).
82Rejected with suggested BSS transitionSteering rejection + hint.AP says "go to my neighbor" - pairs with a BTM candidate list (11v).
126SAE Hash-to-Element requiredH2E-only BSS.6 GHz WPA3: hunting-and-pecking commit rejected; client must use H2E (see RSNXE bit 4).

Tip#

Direction matters: a Deauth FROM the client (TA=client) with reason 3/8 is normal behavior; a Deauth TO the client with 2/6/7/15 is where troubleshooting starts. Spoofed deauth floods show reason 7 at high rate without PMF.
