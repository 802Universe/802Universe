SubfieldBitsMeaningAnalysis Notes
Protocol VersionB0-B1Always 00 (version 0). Value 01 reserved for future.Wireshark: wlan.fc.version. Non-zero = corruption/capture artifact.
TypeB2-B300=Management, 01=Control, 10=Data, 11=Extension.wlan.fc.type
SubtypeB4-B7Frame subtype - see 802.11 Frame Types sheet for all values.wlan.fc.type_subtype combines both.
To DSB81 = frame destined to the Distribution System (client→AP direction for infrastructure data).See address table below - ToDS/FromDS decide Addr1-4 meaning.
From DSB91 = frame exiting DS (AP→client). Management/control frames: both bits 0.ToDS=FromDS=1 → 4-address (WDS/mesh) frame.
More FragmentsB101 = more fragments of this MSDU follow.Fragmentation nearly extinct in modern nets (A-MPDU replaced it); HE adds dynamic fragmentation inside A-MPDU.
RetryB111 = retransmission of an earlier frame.wlan.fc.retry==1 rate = quick PER proxy in captures. >10-15% sustained = investigate.
Power ManagementB121 = STA will be in power-save after this exchange.Watch Null frames toggling this bit - legacy PS signaling (see Power Save sheet).
More DataB131 = AP holds more buffered frames for this PS STA.AP→STA only meaningfully.
Protected FrameB141 = frame body encrypted (WEP/TKIP/CCMP/GCMP).Set on Data and on PMF-protected unicast Management frames.
+HTC / OrderB15Legacy: strictly-ordered service. Modern (QoS frames): 1 = HT Control field present in header.HE uses it for A-Control (OM, BSR...). See HT Control rows below.

REMAINING MAC HEADER FIELDS - IEEE 802.11-2020 §9.2.48 rows#

FieldSizeContentAnalysis Notes
Duration/ID16 bitsMicroseconds of medium reservation (NAV) remaining AFTER this frame - receivers set their NAV timer to it. In PS-Poll instead carries AID (bits 15:14 = 11).Bad Duration values (e.g. 32767 stuck) = NAV attack or buggy driver → "air is idle but nobody transmits" symptoms.
Sequence Control16 bitsFragment Number (4 b) + Sequence Number (12 b, 0-4095, modulo). QoS data: independent sequence counter PER TID; mgmt frames use their own counter.Duplicate detection: same (TA, TID, seq) with Retry=1 → dup. Sequence gaps per TID in captures = loss between capture point and TA.
QoS Control (QoS Data)16 bitsTID (4 b, 0-7 = UP), EOSP (end of service period, U-APSD), Ack Policy (2 b: 00=Normal ACK, 01=No ACK, 10=No explicit / PSMP, 11=Block ACK), A-MSDU Present (1 b), TXOP/queue info (8 b).Ack Policy=11 + no BA session established = silent loss. A-MSDU bit tells you the payload is an aggregate of MSDUs.
HT Control (+HTC)32 bitsPresent when Order/+HTC bit set on QoS/mgmt frame. Three variants: HT (link adaptation, antenna sel), VHT (B0=0,B1=1: MFB/MRQ beamforming feedback), HE (B0=B1=1: A-Control).-
HE A-Control subfieldsvarAggregated control IDs inside HE variant HT Control: OM (Operating Mode - live NSS/BW change), BSR (Buffer Status Report - feeds UL OFDMA scheduler), UPH (UL power headroom), BQR (bandwidth query), CAS.OM Control is how 11ax clients instantly signal "I dropped to 1×1 20 MHz" - faster than IE 199.
Frame Body0-11,454 BMSDU / A-MSDU (encrypted adds CCMP/GCMP header 8 B + MIC 8/16 B) or management fixed fields + IEs.Max body sizes per gen: see Aggregation & Block Ack sheet.
FCS32 bitsCRC-32 over header+body.wlan.fcs.status == "Bad" - only trustworthy in monitor-mode captures that preserve FCS.
Header sizesData (3-addr): 24 B. QoS Data: 26 B. QoS +HTC: 30 B. 4-address QoS: 32 B. Add encryption header: CCMP-128 +8 B (+8 MIC), GCMP-256 +8 B (+16 MIC).
