DECIBEL MATH - rules every wireless engineer must be able to do mentally9 rows#

Rule / AnchorStatementNotes
dB definitiondB = 10·log₁₀(P2/P1) for power; 20·log₁₀(V2/V1) for voltage/field.Ratios only - dimensionless.
dBm definitiondBm = 10·log₁₀(P / 1 mW). Absolute power.0 dBm = 1 mW.
+3 dB / -3 dB×2 / ÷2 power.Memorize with 10s below - covers everything.
+10 dB / -10 dB×10 / ÷10 power.E.g. 26 dBm = 20+3+3 → 100 mW×2×2 = 400 mW.
+1 dB×1.26 (≈ +26%).1 dB rule of thumb: ~25%.
dB + dBm mathdBm + dB = dBm (gain applied). dBm - dBm = dB (a ratio). dBm + dBm = INVALID.Most common link-budget mistake.
dBi / dBdAntenna gain vs isotropic / vs dipole. dBi = dBd + 2.15.Datasheets mix them - check the suffix.
mW→dBm anchors1 mW=0 · 10 mW=10 · 100 mW=20 · 1 W=30 · 4 W=36 dBm.FCC 2.4 GHz max EIRP = 36 dBm point-to-multipoint.
RX-side anchors-30 dBm ≈ 1 µW (very hot) · -50 excellent · -67 voice-grade edge · -72 data edge · -85 marginal · -95 noise-floor region (20 MHz ≈ -101 dBm thermal).Design targets: -65 to -67 dBm for VoWiFi cells.
