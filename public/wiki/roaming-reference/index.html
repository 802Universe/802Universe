802.11r (FT)Mobility Domain IE (tag 54): MDID + FT Policy (key use + resource req protocol) AP announces it supports FTFT Action in RSN IE AKM: type=3 (FT/802.1X) or type=4 (FT/PSK) STA includes MDE (Mobility Domain Element)STA RSN IE must have FT AKM type. 802.11v (BSS TM)Extended Caps IE bit 19: BSS Transition set by APExtended Caps IE bit 19 set by STASTA should set bit 19 in Extended Caps. STA should roam to suggested AP.'Sticky client' problem: STA ignores BTM Request. AP can set Disassociation Imminent bit + force disassoc as last resort. Monitor BTM Accept rate to quantify steering success.
