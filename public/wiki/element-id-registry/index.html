0SSID802.11 baseBeacon, Probe Req/Resp, (Re)Assoc ReqNetwork name, 0-32 bytes. Length 0 = wildcard (Probe Req) or hidden SSID (Beacon). UTF-8 allowed if SSID Encoding bit set.wlan.ssid
1Supported Rates802.11 baseBeacon, Probe, AssocUp to 8 rates. MSB set (0x80) = basic/mandatory rate. Value = rate ÷ 500 kbps (0x82 = basic 1 Mbps). 0xFF in this IE never valid - see BSS Membership Selectors below.wlan.supported_rates
3DSSS Parameter Set802.11 baseBeacon, Probe Resp (2.4 GHz)Current channel number for DSSS/HR-DSSS/ERP PHYs. The classic "what channel is this AP on" field in 2.4 GHz.wlan.ds.current_channel
4CF Parameter Set802.11 baseBeacon (PCF)Contention-free period parameters. PCF obsolete - never seen in modern captures.-
5TIM (Traffic Indication Map)802.11 baseBeacon onlyDTIM Count, DTIM Period, Bitmap Control, Partial Virtual Bitmap. Bit N set = AP holds buffered frames for AID N. AID 0 bit = buffered group traffic (sent after DTIM beacon).wlan.tim.dtim_count / .dtim_period
6IBSS Parameter Set802.11 baseBeacon (IBSS)ATIM window for ad-hoc networks.-
7Country802.11dBeacon, Probe RespCountry string (e.g. "US "), then triplets: first channel, number of channels, max TX power. Drives client regulatory behavior (passive scan lists).wlan.country_info
11BSS Load (QBSS)802.11eBeacon, Probe RespStation Count, Channel Utilization (0-255 = 0-100% of measured airtime busy), Available Admission Capacity. Key roaming/steering input - clients use it to avoid loaded APs.wlan.qbss.cu (channel utilization)
12EDCA Parameter Set802.11eBeacon, Probe Resp, Assoc RespPer-AC CWmin/CWmax/AIFSN/TXOP limit the AP tells clients to use. QoS Info field includes U-APSD flag.wlan.wfa.ie.wme / EDCA fields
13TSPEC802.11eADDTS Action framesTraffic specification for admission control (mean data rate, nominal MSDU size, surplus bandwidth). Used by WMM-AC / voice admission control.wlan.ts_info
14TCLAS802.11eADDTS / SCSTraffic classification (frame filter) associated with a TSPEC or SCS stream.-
32Power Constraint802.11hBeacon, Probe RespdB reduction from regulatory max - local max TX power = country max - constraint.wlan.powercon.val
33Power Capability802.11h(Re)Assoc ReqClient min/max TX power capability.-
34TPC Request802.11hActionRequests TX power / link margin report.-
35TPC Report802.11hBeacon, Probe Resp, ActionTX power and link margin. In beacons: shows AP TX power - useful for verifying power settings in surveys.wlan.tpc.report.tx_power
36Supported Channels802.11h(Re)Assoc ReqChannel ranges the client supports - inspect when investigating DFS-channel client compatibility.-
37Channel Switch Announcement (CSA)802.11hBeacon, Probe Resp, ActionNew channel + switch count(down) + mode (0 = keep transmitting, 1 = stop TX until switch). Critical for DFS events. Count decrements each beacon.wlan.csa.channel_switch_mode / .new_channel / .count
38Measurement Request802.11h/kActionBasic / CCA / RPI / channel-load / noise-histogram / beacon / frame / STA-stats measurement requests (802.11k RRM).wlan.rmreq
39Measurement Report802.11h/kActionReports for the above. Beacon Report = the key 802.11k roaming assist (client-reported neighbor RSSI).wlan.rmrep
40Quiet802.11hBeaconSchedules quiet interval (all STAs silent) so AP can perform radar CAC measurement.-
42ERP Information802.11gBeacon, Probe Resp (2.4 GHz)NonERP_Present, Use_Protection, Barker_Preamble_Mode bits. Use_Protection=1 → 802.11b protection (CTS-to-self/RTS) active - classic 2.4 GHz throughput-drop signature.wlan.erp.use_protection
45HT Capabilities802.11nBeacon, Probe, (Re)AssocClient/AP HT abilities: supported MCS bitmap, 40 MHz support, SGI, SM Power Save, A-MPDU factor/density, LDPC, STBC, max A-MSDU.wlan.ht.capabilities
46QoS Capability802.11eAssoc when no full EDCA IECondensed QoS Info field only.-
48RSN (Robust Security Network)802.11iBeacon, Probe, (Re)Assoc ReqTHE security IE: group cipher, pairwise cipher list, AKM list, RSN Capabilities (MFPC/MFPR = PMF bits!), PMKID list, group mgmt cipher. Mismatch here = assoc/4-way failures. See dedicated RSN sheet.wlan.rsn.* (wlan.rsn.akms.type, wlan.rsn.pcs.type)
50Extended Supported Rates802.11gBeacon, Probe, AssocRates beyond the 8 that fit in IE 1. Also carries BSS Membership Selectors (MSB set): 127 = HT PHY required, 126 = VHT PHY, 122 = HE PHY, 123 = SAE Hash-to-Element only.wlan.extended_supported_rates
51AP Channel Report802.11kBeacon, Probe RespOperating class + channel list of neighboring APs - reduces client scan time.-
52Neighbor Report802.11kAction (Neighbor Rpt Resp)BSSID, BSSID Info, op class, channel, PHY type of neighbor APs (+ optional FT Mobility Domain subelement). Core of 802.11k-assisted roaming.wlan.nreport
54Mobility Domain (MDE)802.11rBeacon, Probe, (Re)AssocMDID (2 bytes) + FT capability bits (over-DS allowed, resource request). Same MDID = fast transition possible between APs.wlan.mobility_domain.mdid
55Fast BSS Transition (FTE)802.11rAuth (FT), (Re)AssocMIC, ANonce, SNonce, R0KH-ID, R1KH-ID for the FT 4-way-replacing exchange. Debug 802.11r roam failures here.wlan.ft.*
56Timeout Interval (TIE)802.11r/wAssoc Resp, FT framesType 1 = reassoc deadline, type 2 = key lifetime, type 3 = SA Query retry timeout (association comeback time - seen with PMF).wlan.timeout_interval
59Supported Operating Classes802.11y/-2012(Re)Assoc ReqOperating classes (band+BW combos, Annex E) the client supports. How APs learn a client is 6 GHz-capable pre-association.-
60Extended CSA (eCSA)802.11y/-2012Beacon, ActionCSA + operating class - needed when switching bands/BW, not just channel.wlan.ext_csa.*
61HT Operation802.11nBeacon, Probe RespPrimary channel, secondary offset (above/below/none), HT protection mode, Basic MCS set. Where 40 MHz plan and greenfield/mixed protection is announced.wlan.ht.info.*
70RM Enabled Capabilities802.11kBeacon, (Re)AssocBitmask of which 802.11k measurements the device supports (neighbor report, beacon passive/active/table, link measurement...). Check before blaming a client for ignoring 11k.wlan.rmcap
71Multiple BSSID802.11v/axBeacon, Probe RespAdvertises co-located BSSIDs (nontransmitted profiles) inside one beacon. MANDATORY concept on 6 GHz. MaxBSSID Indicator n → 2^n BSSIDs share one beacon.wlan.mbssid.*
74Overlapping BSS Scan Parameters802.11nBeaconScan intervals a 40 MHz 2.4 GHz BSS asks clients to use for OBSS coexistence checks.-
76Management MIC (MME)802.11wBroadcast Deauth/Disassoc, Beacon (opt)BIP integrity element protecting broadcast management frames: Key ID, IPN (replay counter), MIC. Presence = PMF group protection active.wlan.mme.*
84SSID List802.11-2012Probe ReqMultiple SSIDs in one directed probe - reduces scan airtime.-
107Interworking802.11uBeacon, Probe, AssocAccess Network Type (private/free-public/chargeable...), Internet bit, Venue Info, HESSID. Hotspot 2.0 / Passpoint foundation.wlan.interworking.*
108Advertisement Protocol802.11uBeacon, Probe RespAdvertises ANQP (and other query protocols) supported - enables pre-association GAS/ANQP queries.-
111Roaming Consortium802.11uBeacon, Probe RespOI (Organization Identifiers) of roaming federations - Passpoint clients match against installed credentials.wlan.rcons.*
113Mesh Configuration802.11sMesh BeaconPath selection protocol (HWMP), metric, congestion control, mesh formation info.wlan.mesh.config.*
114Mesh ID802.11sMesh Beacon, ProbeMesh network name (analog of SSID for mesh BSS).wlan.mesh.id
127Extended Capabilities802.11-2012+Beacon, Probe, AssocGrab-bag capability bitmap: bit 19 = BSS Transition (11v BTM!), bit 12 = proxy ARP, bit 31 = Interworking, bit 72 = FILS Capability, bits 77/78 = TWT Requester/Responder. First place to check "does this client support 11v".wlan.extcap (bit 19 = BTM)
133CCX / Cisco proprietary rangeVendorBeacon, AssocIDs 133/136/149/150 etc. historically used by Cisco CCX (Aironet). Seen in captures on Cisco WLANs.wlan.cisco.ccx1
148DMG Capabilities (60 GHz)802.11adDMG frames60 GHz capability advertisement.-
191VHT Capabilities802.11acBeacon, Probe, AssocMax MPDU length, supported channel width set (160/80+80), RX/TX VHT-MCS maps per NSS, SU/MU beamformer/beamformee caps, max A-MPDU exponent.wlan.vht.capabilities
192VHT Operation802.11acBeacon, Probe RespChannel width (0=20/40, 1=80/160/80+80), Channel Center Segment 0/1, Basic VHT-MCS set. Segment1 ≠ 0 with width 1 = 160 or 80+80 in use.wlan.vht.op.*
193Extended BSS Load802.11acBeaconMU-MIMO capable STA count + spatial-stream underutilization - richer load signal than IE 11.-
194Wide Bandwidth Channel Switch802.11acBeacon (with CSA), ActionNew channel width + segments for CSA to 80/160 MHz targets.-
195Transmit Power Envelope802.11ac/axBeacon, Probe RespMax TX power per BW (20/40/80/160). On 6 GHz carries LPI vs SP power sets - key for AFC/6 GHz debugging.wlan.tpe.*
197AID802.11acAssoc Resp (VHT)Association ID container in VHT association.-
199Operating Mode Notification802.11acAction, AssocClient dynamically signals current max BW / NSS (e.g. drops to 1SS 20 MHz to save power). Explains "client stuck at low rate" mysteries.wlan.opmode.*
201Reduced Neighbor Report (RNR)802.11axBeacon, Probe Resp (2.4/5 GHz)TBTT info of co-located APs - THE out-of-band 6 GHz discovery mechanism: 2.4/5 GHz beacons advertise the 6 GHz BSS (op class, channel, short-SSID, BSSID, 20 MHz PSD).wlan.rnr.*
216Target Wake Time (TWT)802.11ah/axBeacon, ActionBroadcast TWT schedules; individual TWT negotiated via Action frames. See Power Save & TWT sheet.wlan.twt.*
221Vendor Specific802.11 baseEverywhereOUI + vendor payload. Carries WPA1 (OUI 00:50:F2 type 1), WMM/WME (00:50:F2 type 2), WPS (00:50:F2 type 4), Hotspot 2.0 (50:6F:9A type 0x10), P2P, Apple/Aruba/Cisco extensions. Multiple instances per frame normal.wlan.tag.oui
244RSN Extension (RSNXE)802.11-2020/WPA3Beacon, Probe, Assoc, (M2/M3)Extended RSN capability bits: bit 4 = SAE Hash-to-Element (H2E), bit 5/6 = SAE-PK. WPA3 6 GHz REQUIRES H2E. RSNXE must also be echoed inside EAPOL M2/M3 - mismatch drops the 4-way.wlan.rsnx.*
255Element ID Extension802.11ax+EverywhereEscape code: real ID = 255 + Extension ID byte that follows. All HE/EHT elements live here (below).wlan.ext_tag.number
